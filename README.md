# GitGrade

See your GitHub the way a recruiter sees it.

GitGrade scores every public repo on an account against a checklist of repo
hygiene rules, grades the account, and ranks the repos worst to best with the
exact fix for every failed check.

Read-only. No login, no backend.

## Running it

    npm install
    npm run dev

## Scripts

    npm run dev      start the dev server
    npm test         run the test suite
    npm run lint     lint
    npm run build    typecheck and build
